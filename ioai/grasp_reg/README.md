# Grasp Registration

## Installation
To install the required packages, run:
```bash
pip install -r requirements.txt
```

## Usage
An example of how to use the grasp registration:
```bash
python example.py --object_name <object_name>
``` 
To visualize the grasp registration, run:
```bash
python grasp_reg_vis.py --object_name <object_name>
```
